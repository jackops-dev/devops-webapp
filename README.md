# DevOps Webapp 🚀

This project is a hands-on learning project to understand modern backend development and DevOps workflows.

## Features

- Express.js backend
- REST API with:
  - `GET /`
  - `GET /users`
- JSON responses
- Automated testing with Jest & Supertest
- Dockerized application
- Kubernetes deployment using k3d

## Tech Stack

- Node.js
- Express
- Docker
- Kubernetes (k3d)
- Jest
- Supertest
- Git
- GitHub

## Run locally

```bash
npm install
node index.js
